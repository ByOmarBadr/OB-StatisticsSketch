# OB-StatisticsSketch
OB-StatSketch is a free, offline-first interactive statistics learning and graphing lab. 

Explore confidence intervals, hypothesis testing, ANOVA, chi-square tests and statistical power through visual lessons, guided examples, critical-value calculators and downloadable graphs. One HTML file, no installation required.

Developed to make inferential statistics accessible, interactive, and enjoyable for learners!
